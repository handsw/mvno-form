==================================================================

이 문서만 순서대로 따라 하면 됩니다. 개발 지식은 필요 없습니다.
한 단계가 끝나면 [ ] 칸에 표시하면서 진행하세요.
처음 세팅은 30분~1시간이면 끝납니다.


------------------------------------------------------------------
 0. 이 프로그램이 하는 일 (먼저 읽어보세요)
------------------------------------------------------------------

매장(오프라인)에서 알뜰폰을 개통할 때 쓰는 가입신청서 웹페이지입니다.
고객 정보를 화면에서 입력하고 서명한 뒤 A4 3장으로 인쇄합니다.

  - 입력한 정보는 어디에도 저장되거나 전송되지 않습니다.
    인쇄가 끝나고 창을 닫으면 사라집니다. (서버/DB 없음)
  - 그래서 관리할 계정이나 비밀번호가 없고, 웹사이트로 올려두기만 하면 됩니다.

들어있는 화면
  index.html        첫 화면: LG망 / KT망 선택 + 법정대리인 동의서 버튼
  LG_v3.html        LG망 가입신청서
  KT_v2.html        KT망 가입신청서
  guardian.html     법정대리인(미성년자 부모) 가입동의서
  LG_corp_v4.html   법인 전용 신청서 (첫 화면에 없음, 전용 링크로만 접속)

나머지 파일
  app.js / style.css / fonts   화면 동작·디자인·글꼴 (모든 신청서가 같이 씀)
  _redirects                   법인 전용 링크 설정
  AGENTS.md                    개발자·AI 도구용 설명서

필요한 계정 (회사 메일로 만드는 것을 권장합니다)
  - GitHub      https://github.com          (파일 보관)
  - Cloudflare  https://dash.cloudflare.com  (웹사이트 주소 제공, 무료)

받은 파일
  - 오프라인가입신청서_인수인계.zip            프로그램 전체
  - 오프라인가입신청서_인수인계_가이드.txt      지금 보고 있는 이 문서


------------------------------------------------------------------
 1. 압축 풀기
------------------------------------------------------------------

[ ] 1-1. C 드라이브에 Projects 폴더를 만듭니다.  (C:\Projects)
[ ] 1-2. zip 파일 마우스 오른쪽 클릭 > "압축 풀기" > 위치 C:\Projects
[ ] 1-3. C:\Projects\mvno-form 폴더 안의 index.html 을 더블클릭해서
         브라우저에 첫 화면이 나오면 정상입니다.


------------------------------------------------------------------
 2. GitHub에 올리기
------------------------------------------------------------------

[ ] 2-1. https://github.com 회원가입/로그인
         (회사 Organization이 있으면 그 안에 만들어도 됩니다)
[ ] 2-2. GitHub Desktop 설치 https://desktop.github.com > 설치 > 로그인
[ ] 2-3. GitHub Desktop 상단 메뉴 File > Add local repository
         > Choose... 로 C:\Projects\mvno-form 선택
         > 파란 글씨 "create a repository" 클릭 > Create repository
[ ] 2-4. 상단 "Publish repository" 클릭
         > Name: mvno-form
         > "Keep this code private" 체크 (비공개 권장. 비공개여도 사이트는 정상 동작)
         > Publish repository


------------------------------------------------------------------
 3. 웹사이트 주소 만들기 (Cloudflare Pages)
------------------------------------------------------------------

[ ] 3-1. https://dash.cloudflare.com 회원가입/로그인
[ ] 3-2. 왼쪽 메뉴 "Workers & Pages" > Create(생성)
         > 상단 "Pages" 탭  ★ Workers가 아니라 Pages
         > "Connect to Git" 또는 "Import an existing Git repository"
         > GitHub 연결 허용 > mvno-form 선택 > Begin setup
[ ] 3-3. 아래처럼 입력
             Project name            : 원하는 이름 (주소가 됩니다. 예: ajd-mvno-form)
             Production branch       : main
             Framework preset        : None
             Build command           : (비워둠)
             Build output directory  : /
         > Save and Deploy
[ ] 3-4. 1분쯤 뒤 https://(프로젝트이름).pages.dev 주소가 생깁니다.
         접속해서 첫 화면이 나오면 성공입니다.

  이후로는 GitHub에서 파일을 고칠 때마다 1~2분 안에 사이트에 자동 반영됩니다.


------------------------------------------------------------------
 4. 주소 정리하고 매장에 안내하기  ★ 중요
------------------------------------------------------------------

기존 주소는 전 담당자 개인 계정이라 인수인계 후 닫힙니다.
매장에서 쓰는 즐겨찾기/바로가기/QR코드를 새 주소로 바꿔야 합니다.

  일반 신청서 (첫 화면)    https://(프로젝트이름).pages.dev
  법정대리인 동의서         https://(프로젝트이름).pages.dev/guardian
  법인 전용 신청서          https://(프로젝트이름).pages.dev/f6pq8acy7w

[ ] 4-1. 위 3개 주소를 각각 열어서 화면이 나오는지 확인
[ ] 4-2. 매장/영업 담당자에게 새 주소 공지
[ ] 4-3. (선택) 회사 도메인을 쓰고 싶으면
         Cloudflare 프로젝트 > Custom domains > Set up a custom domain
         에 도메인을 넣고, 화면 안내대로 회사 도메인 관리자에게 설정을 요청합니다.

  ※ 법인 전용 링크(f6pq8acy7w)는 아는 사람만 들어오도록 일부러 알기 어렵게
     만든 주소입니다. 바꾸고 싶으면 아래 "6-3"을 참고하세요.

------------------------------------------------------------------
 5. 신청서 문구 고치기 (예: 동의서 문구, 요금제명 변경)
------------------------------------------------------------------

[ ] 5-1. GitHub 저장소 페이지에서 고칠 파일을 클릭합니다.
         LG망 > LG_v3.html / KT망 > KT_v2.html / 법인 > LG_corp_v4.html
         법정대리인 > guardian.html
[ ] 5-2. 오른쪽 위 연필 아이콘(Edit this file) 클릭
[ ] 5-3. Ctrl+F 로 고칠 문구를 찾아서 글자만 바꿉니다.
         ★ < > 기호로 둘러싸인 부분(태그)은 건드리지 마세요. 글자만 고칩니다.
[ ] 5-4. 오른쪽 위 "Commit changes..." > 무엇을 고쳤는지 한 줄 적기 > Commit changes
[ ] 5-5. 2분 뒤 사이트를 새로고침해서 확인
[ ] 5-6. ★ 반드시 인쇄 미리보기(Ctrl+P)로 A4 3장 안에 들어가는지 확인
         글자가 늘어나 4장으로 넘어가면 문구를 줄이거나 개발자에게 요청하세요.

  ※ LG와 KT 신청서는 문구가 거의 같습니다. 공통 문구를 고칠 때는
     두 파일 모두 고쳐야 하는지 확인하세요. (법인 신청서도 마찬가지)

  ※ 잘못 고쳤을 때 되돌리기
     GitHub 저장소 > 파일 클릭 > 오른쪽 위 "History" > 고치기 전 버전을 열어
     내용을 확인하고, 개발자에게 되돌려 달라고 요청하거나 그 내용으로 다시 고칩니다.


------------------------------------------------------------------
 6. 신청서를 새 버전으로 바꿀 때 (내용이 크게 바뀌는 경우)
------------------------------------------------------------------

큰 개편은 기존 파일을 복사해 새 이름(v4, v5...)으로 만들고,
다 만든 다음 연결만 새 파일로 바꾸는 방식입니다.
그러면 작업 중에도 매장에서는 기존 신청서를 계속 쓸 수 있습니다.

  6-1. 일반 신청서(LG/KT) 연결 바꾸기
       index.html 을 열어(연필) 아래 줄의 파일 이름을 새 파일로 바꿉니다.
           location.href='LG_v3.html'   →  location.href='LG_v4.html'
           location.href='KT_v2.html'   →  location.href='KT_v3.html'

  6-2. 법인 신청서 연결 바꾸기
       _redirects 파일을 열어(연필) 오른쪽 파일 이름만 바꿉니다.
           /f6pq8acy7w  /LG_corp_v4  200
                        ~~~~~~~~~~~ 이 부분만  예) /LG_corp_v5

  6-3. 법인 전용 링크 주소 자체를 바꾸고 싶을 때
       같은 줄의 왼쪽(/f6pq8acy7w)을 영어+숫자 10자 정도로 바꿉니다.
       바꾸면 기존 링크는 더 이상 열리지 않으니 법인 담당자에게 새 링크를 공지하세요.

  ※ 새 파일 만들기와 큰 수정은 개발 작업입니다. 개발자 또는 AI 도구에게
     AGENTS.md 를 보여주고 요청하는 것을 권장합니다.


==================================================================
 자주 생기는 문제
==================================================================

Q. 인쇄하면 4장이 나와요.
A. 브라우저 인쇄 설정에서 용지 A4, 배율 "기본값", 여백 "기본값"인지 확인하세요.
   설정이 맞는데도 넘치면 최근에 늘어난 문구 때문입니다. (5-6 참고)

Q. 서명이 인쇄물에 안 나와요.
A. 서명 창에서 서명한 뒤 "서명 완료" 버튼을 눌렀는지 확인하세요.
   크롬 또는 엣지 최신 버전을 사용하세요.

Q. 고쳤는데 사이트에 반영이 안 돼요.
A. Cloudflare > 프로젝트 > Deployments 에서 최신 배포가 Success 인지 확인하세요.
   Success인데도 그대로면 브라우저에서 Ctrl+F5 (강력 새로고침).

Q. 법인 링크가 "페이지를 찾을 수 없음"으로 나와요.
A. _redirects 오른쪽에 적은 파일 이름이 실제 파일 이름과 같은지 확인하세요.
   (.html 은 붙이지 않습니다)

Q. 폴더에 .exs / .exo 로 끝나는 파일이 생겼어요.
A. 회사 보안 프로그램이 문서를 암호화한 흔적입니다. GitHub에 올리지 마세요.
